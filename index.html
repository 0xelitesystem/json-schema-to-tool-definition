JSON Schema to Tool Definition

Generate tool definitions in your browser

Paste a JSON Schema describing a function's parameters. The tool wraps it into a function/tool-calling definition in both the OpenAI function-calling format and the Anthropic tool format. Everything runs locally.

All conversion happens locally. The schema is never sent to any server.
